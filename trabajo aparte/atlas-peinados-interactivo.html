Busca por silueta y por partes del cabello. Elige una receta para construir un prompt PixAI sin mezclar rasgos contradictorios.

Explorar peinados

Las recetas se generan combinando rasgos catalogados; no se presentan como cientos de imágenes originales verificadas. Las referencias visuales externas están enlazadas a sus fuentes.

Constructor de prompt

Selecciona una receta y ajusta las partes. El prompt usa términos ingleses habituales en generadores de imagen.

Nota de uso: las imágenes de referencia pertenecen a sus autores. Este atlas enlaza fuentes; no implica permiso para entrenar modelos, redistribuir imágenes o incorporarlas como assets del proyecto.

Selección visual: láminas que sí permiten comparar

Curé primero las láminas con muchos peinados en una misma imagen, contornos legibles y diferencias visibles. Pulsa una miniatura para abrir la fuente. Las referencias alojadas por terceros sirven para estudiar: no son assets libres por defecto.

Criterios: variedad por lámina, contraste de siluetas, limpieza del line art, vista frontal y facilidad para localizar un diseño. No se han contado copias de la misma lámina como variedad nueva.
