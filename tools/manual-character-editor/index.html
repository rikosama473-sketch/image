Herramientas

Polígono: clic en cada punto y doble clic para cerrar. Pincel: pintá directamente sobre el área que querés aislar. El borde se hace manual; ninguna IA decide por vos.

Precisión

Selección actual

La selección es una máscara editable. Exportar crea un PNG transparente; no modifica el original salvo que uses borrar, extraer o recortar.

Fondo

Elimina colores parecidos al píxel de la esquina superior izquierda, solo si están conectados al borde. Mirá el resultado y usá Deshacer o Restaurar si toca el personaje.

Abrí una imagen para empezar.
100%
Esperando una imagen. Todo el procesamiento de píxeles ocurre en tu navegador.

Capas

Las capas conservan las coordenadas del lienzo para que puedas superponer cabello, cabeza y cuerpo sin que cambien de sitio.

Recortar lienzo

Usá la herramienta Rectángulo y marcá el encuadre. Esto recorta todas las capas a la misma zona y mantiene el alineado.

El editor no inventa los píxeles ocultos detrás del cabello o la cabeza. Para un cambio de peinado limpio, separá las piezas con el pincel/lazo y luego retocá el cuello o la zona tapada.

Flujo recomendado

1. Abrí la imagen original.
2. Elegí Polígono o Pincel y marcá el cabello.
3. Pulsá “Extraer selección” y dejá activada la opción de quitarlo del original.
4. Repetí para flequillo, cabello trasero, cara, ropa o accesorios.
5. Ocultá/mostrá capas para comprobar cortes y exportá cada PNG.
6. Guardá el proyecto JSON para continuar después.
