Inspecciona el conjunto, etiqueta cabello/ropa/piernas, registra el modelo base y la LoRA de origen, identifica la LoRA destino que quieres usar/probar y revisa los permisos. Los archivos no se suben ni se modifican.

1. Cargar carpeta y manifiesto

Abre esta herramienta desde tu clon local. Selecciona la carpeta raíz del repositorio para que las rutas coincidan con data/training-labels.csv. El nombre original se conserva. Los identificadores de modelo base/LoRA se anotan aparte y sirven también para buscar imágenes relacionadas. La herramienta solo descarga un CSV nuevo; no escribe sobre los originales.
