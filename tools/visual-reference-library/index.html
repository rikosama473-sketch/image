+ Añadir referencia visual

Pegá el enlace del pin y, si está disponible, la URL directa de la imagen para verla como miniatura. No descargamos pins ni quitamos sus marcas de agua. El estado inicial es “sin revisar” y “derechos sin verificar”.

+ Importar muchos enlaces de Pinterest de una vez

Pegá URLs HTTPS de pins o tableros, una por línea. Se crea una ficha provisional por enlace para abrirla, nombrarla y clasificarla. No se simula que las imágenes ya fueron analizadas; la vista previa solo aparece si el catálogo ya tiene una URL directa de imagen.

Crear variación a partir de referencias seleccionadas

Marcá 1 o más fichas de una misma familia visual en la galería. Esto crea una receta descriptiva, no un PNG. Después pulsá “Probar en editor IA” para pasar la instrucción al editor existente; la generación requiere que su servicio local y la clave del proveedor estén configurados. Los enlaces de Pinterest no se cargan como imágenes de referencia automáticamente: subí la referencia manualmente en el editor.

Cargando los catálogos de IMAGE…
La vista local toma las 764 entradas indexadas en tools/avatar-maker/assets/image-library.json y las capas de catalog.json. Los nombres genéricos no se convierten automáticamente en etiquetas confirmadas: la clasificación visual se guarda como anotación hasta que se revise cada archivo. Para aplicar al repositorio las anotaciones exportadas, ejecutá python scripts/apply_visual_reference_annotations.py image-visual-reference-library-export.json. Para producir hojas de contacto locales, ejecutá python scripts/build_visual_contact_sheets.py desde la raíz del repositorio.
