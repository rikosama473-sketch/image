# Catálogo de prompts de personajes

El primer catálogo visual está en [Prompt 1](prompt-1/README.md).

Las identidades Pibara, Chie y Sunna están separadas del peinado, el largo, la ropa, la pose y el encuadre para poder reutilizar el prompt de cada personaje con variaciones. La asignación de nombre a las referencias es provisional porque las imágenes revisadas no conservan los prompts originales ni metadatos suficientes para verificar el vínculo.

La clasificación de las 759 imágenes está en curso. Solo se retiran copias exactas verificadas; no se eliminan variantes de peinado ni imágenes únicas basándose solo en semejanza visual.
